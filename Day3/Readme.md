DAY 3
1. Majority Element: Find the element that appears more than half the times in the given array. Approach: Use a hashmap to store the frequency of each element. Traverse the array and update its frequency. If any element's frequency becomes greater than half the array length, return it. Time Complexity: O(n) Space Complexity: O(n)
2. First Non-Repeating Element: Find the first element that appears only once in the given array. Approach: Use a hashmap to count the frequency of each element. Traverse the array again and return the first element whose frequency is 1. If no such element exists, return -1. Time Complexity: O(n) Space Complexity: O(n)
3. Count Frequencies of Array Elements: Count how many times each element appears in the given array. Approach: Use a hashmap to store each element and its frequency. Traverse the array and increase the frequency of each element whenever it appears. Return the hashmap containing all elements and their counts. Time Complexity: O(n) Space Complexity: O(n)
